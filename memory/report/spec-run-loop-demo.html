方案 A — 轮次分组卡
每轮是一张折叠卡，内部有 run/detect/repair 三段细节。信息最完整，适合需要排查问题时展开看。
方案 B — 紧凑时间轴
每步一行，竖向排列，像 git log。最省空间，流程感最强，但细节少。
方案 C — 综合流水线卡
所有轮次在一张表格里对比，最容易一眼看出"哪轮出了什么问题"，底部附最终统计。
