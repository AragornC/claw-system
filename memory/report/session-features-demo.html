Agent 对话框功能优化

✦ Demo 交互演示

针对 AgentPanel + SubHeader 的两个核心优化： ① 对话后自动提炼生成 Session 标题（支持手动修改）； ② 会话历史持久化，重启后仍可查看历史对话。

1

对话自动命名

Auto Title
首次发送消息后，后台自动调用 LLM 根据用户首条消息 + 模型首次回复提炼 6-12 字的标题，异步写回 session.name。 标题生成期间 tab 显示加载状态，生成后平滑切换并附 ✦ AI 角标。 用户仍可右键「重命名」覆盖 AI 生成的名字。
交互演示 — 点击「发送」触发自动命名流程
+
实现流程说明
1
用户发送第一条消息，handleSendMessage 检测到 messages.length === 0，tab 切换为 生成中… 动画
2
同时并行启动两个异步任务：① 正常对话流（流式输出回复）； ② 仅凭用户这条消息，立刻向 LLM 发起标题生成请求
3
标题请求仅需用户一句话，通常 几百毫秒 就返回， 远早于对话流结束——用户还没读完回复，标题已悄悄写好
4
收到标题后调用 handleRenameSession(id, title)， tab 标签平滑更新并附上 ✦ AI 角标
5
用户仍可右键「重命名」手动修改，修改后 AI 角标消失，标记为用户自定义名称
⚡
Title 生成 System Prompt
你是一个对话标题生成器。根据以下对话内容，用6-12个中文字提炼一个简洁、准确的标题。只返回标题文本，不加引号或其他内容。
🔒
手动修改优先
session 增加 isNameCustomized: boolean 字段。一旦用户手动重命名，不再触发 AI 覆盖，已标记的 AI 角标也移除。
2

会话历史持久化

Persistent History
将 sessions 数据持久化到 localStorage（或通过 Tauri invoke 写入本地文件），重启后自动恢复。 左侧历史面板按日期分组展示所有 session，支持搜索、点击切换、右键删除/重命名。

持久化方案说明
💾
存储方案：Zustand chatStore + persist
新增 chatStore.ts，将 sessions 数组（含 id、name、messages、createAt 等） 通过 Zustand persist 写入 localStorage。 App.tsx 中的 sessions state 替换为从 chatStore 读取，删除原 useState。
📋
数据结构扩展
Session 增加 createdAt: number、updatedAt: number、 isNameCustomized: boolean，用于日期分组排序和命名策略判断。
🗂
历史面板 UI 入口
SubHeader 右侧历史图标点击展开 侧边抽屉（或 dropdown）， 按今天 / 昨天 / 本周 / 更早分组。支持关键词搜索 session 名称与消息内容。 右键菜单提供重命名、删除操作，已删除数据移入回收站或直接清除。
⚠
存储容量兜底
localStorage 单域名上限约 5MB。长期使用后需做消息截断（每条 session 仅保留最近 N 轮） 或提供「清理 60 天前对话」的设置项。未来可迁移到 Tauri 文件系统（fs plugin）以突破限制。

✦ 实施方案总览 — 最小改动原则

① 新增 chatStore.ts
基于 Zustand + persist 新建 src/store/chatStore.ts， 接管 App.tsx 中的 sessions / activeId 状态，key 设为 claw-chat-store。 持久化 partialize 仅保存必要字段，messages text 做长度截断。
② App.tsx 最小修改
用 useChatStore 替换原 useState 的 sessions/activeId， handleSendMessage 中检测首条消息后异步触发 generateSessionTitle()， 其余逻辑基本不动。
③ generateSessionTitle()
接收 providerId + modelId + firstUserMsg（只需用户一句话）， 与对话流并行调用 chatStream 发 title prompt。 通常几百毫秒先于对话流完成，回调 renameSession(id, title)。 无需等待 AI 回复，用户问题本身已足够提炼标题。
④ SubHeader 历史面板
历史图标点击展开 Dropdown，读取 chatStore 全量 sessions 按 updatedAt 倒序排列， 按日期分组。点击条目调 setActiveId，右键菜单调 deleteSession。 搜索框过滤 session name（可选：也搜 messages 文本）。
