Agent 自主学习与沉淀 — 能力边界在哪？

一个真正的交易员会从经验中学习、沉淀直觉、适应市场。Agent 能不能做到这些？哪些可以自主，哪些必须人类监督？

先看真实交易员是怎么成长的

人类交易员的学习循环
观察 — 每天看盘、读新闻、跟踪持仓
记录 — 交易日志：什么时候买的、为什么、结果如何
复盘 — 定期回顾：哪些判断对了、哪些错了、为什么
总结 — 提炼规律："RSI 超卖 + 放量时抄底胜率高"
验证 — 用小仓位或模拟盘测试新想法
迭代 — 有效则纳入体系，无效则放弃
Agent 可以模拟哪些？
观察 — ✓ 自动监控市场、新闻、持仓变动
记录 — ✓ 自动记录每次分析和建议的结果
复盘 — ✓ 自动对比预测 vs 实际，统计准确率
总结 — ⚠ 可以发现统计规律，但可能过拟合
验证 — ✓ 可以在历史数据 / 模拟盘上自动回测
迭代 — ⚠ 更新策略规则 → 需要用户审批
关键洞察：交易员的学习循环有 6 步，前 5 步 Agent 都可以自主完成。
唯一需要人类介入的是最后一步"迭代"——把新规律纳入正式体系。

原因：Agent 可能过拟合（把噪声当规律）、幸存者偏差（只记住成功的）、因果倒置（相关不等于因果）。
人类审批这一步，就是防止 Agent "学到错误的教训"。

自主学习的实际场景

场景：Agent 发现一个因子正在失效
持续运行 · 自主 AUTO
Agent 每天自动计算所有在用因子的滚动 IC 值。
发现 volume_zscore 因子的 IC 从 3 个月前的 0.08 持续下降到 0.02。
分析原因 · 自主 AUTO+通知
Agent 自动排查：搜索近期市场结构变化、检查数据源质量、对比其他品种表现。
结论：近期高频交易量增加，导致传统成交量异常信号被淹没。
推送通知给用户。
提出改进方案 · 自主 AUTO+通知
Agent 研究替代方案，提出两个改进方向：
A) 改用相对成交量（当前量/同时段均量），过滤高频噪声
B) 引入 VWAP 偏离度替代原始 Z-Score
并在模拟盘上自动回测了两个方案：A 的 IC=0.06，B 的 IC=0.05。
提交 PR 式审批 · 需审批 需审批
Agent 向用户提交一份"因子更新提案"：
问题：volume_zscore IC 从 0.08 衰减至 0.02
原因：高频交易噪声
建议：替换为方案 A（相对成交量），回测 IC=0.06
影响：依赖此因子的策略 X、Y 需要重新回测

等待用户审批。
用户决策
用户审阅后：批准方案 A → Agent 自动更新因子定义和相关策略。
或：拒绝 → Agent 保持原因子，继续监控。
或：要求更多数据 → Agent 补充更长周期的回测。

为什么"完全自主学习"很危险 必须理解

过拟合
Agent 发现"周二 BTC 涨的概率是 68%"。真的是规律吗？还是数据噪声？
如果它自主把"周二加仓"写进策略，就是在用噪声做决策。
幸存者偏差
Agent 记住了 10 次成功的抄底，忘了 50 次失败的。
然后"学到"了"RSI<20 就应该抄底"——忽略了大部分时候 RSI<20 是继续跌的。
策略漂移
Agent 一点一点微调参数：止损从 5% 调到 7%，再到 10%，再到 15%...
每次微调看起来都有"数据支持"，但整体已经从保守策略漂移成了赌博。
对抗性失效
Agent 学到了一个有效的模式，越来越依赖它。
但市场参与者也在学习——当太多人用同一个策略时，策略就会失效。Agent 却意识不到。
正确做法：学习 + 审批分离
Agent 可以无限学习和发现，但修改规则永远需要人类审批。
就像基金里的初级研究员：可以无限做研究，但调仓决策是基金经理的。
正确做法：多层验证
Agent 发现的"规律"必须通过：
1) 足够长的样本期 2) 多品种交叉验证 3) 模拟盘实测
全部通过后才提交给用户审批。

在 Harness 架构中的位置

自主学习不是新的一层，它是 State 层的扩展
在嵌套架构里，学习循环是 State（状态与记忆）层的一部分，运行在 Query Loop 引擎内。
Reliability
  └─ Control Plane（配置 + 学习审批规则：什么样的提案需要审批）
    └─ Query Loop（引擎，驱动学习循环的定时任务）
      ├─ P-G-E（Evaluator 也用于验证 Agent 的"发现"是否可靠）
      ├─ Tools
      └─ State ← 扩展点
         ├─ 会话状态（短期）
         ├─ Track Record（推荐追踪、准确率）
         ├─ Insight Store（发现的规律、待审批提案）
         └─ Skill Evolution（因子衰减记录、参数变更历史）
总结一句话：

Agent 可以像交易员一样不停地观察、记录、复盘、发现规律——这些全部可以自主运行。
但是"把发现的规律变成行动规则"这一步，永远需要用户拍板。

这不是保守，这是与真实世界一致的设计——
即使是顶级对冲基金，研究员也不能自己改策略上线，必须经过 PM 审批 + 风控签字。
