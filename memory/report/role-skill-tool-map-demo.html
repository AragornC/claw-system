● = 可调用    - = 不可调用    place_order / cancel_order 不属于任何角色，只在用户确认后由系统直接执行
两个重要设计决策：

1. place_order 不属于任何角色。没有任何 Agent 角色可以直接下单。下单是"用户确认后系统执行"，不经过 Agent 的 LLM 推理。

2. Coordinator 不调研究类工具。它只调 notify（推送给用户），不调 web_search / get_klines。它的输入是其他角色的研究报告，不是原始数据。这保证它是"综合者"而非"又一个分析师"。
